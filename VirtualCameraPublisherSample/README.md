# VirtualCameraPublisherSample

This is a super simple sample scene which publishes several virtual cameras
using the com.meta.xr.virtualcamerapublisher package.

The scene is not interactable, and just shows an environment with a few floating
objects.

The following assets may be of interest in this project, when referring to it as
an example of a Virtual Camera Publisher integration:

1. Example of how to call into the API:
   [UnityVideoCapture.cs](./Assets/VirtualCameraPublisherSample/Scripts/UnityVideoCapture.cs)

2. Example AndroidManifest:
   [AndroidManifest.xml](./Assets/Plugins/Android/AndroidManifest.xml)
